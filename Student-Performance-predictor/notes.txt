5️⃣ Check data distribution

For numerical columns:

df.hist(figsize=(10,8))
plt.show()

This shows:

Are values evenly distributed?
Are there outliers?
Is the data skewed?


6️⃣ Correlation Matrix ⭐

One of the most important steps.

plt.figure(figsize=(8,6))
sns.heatmap(df.corr(numeric_only=True), annot=True, cmap="coolwarm")
plt.show()

This tells you:

Which features strongly affect Exam Score.
Which features are weakly related.
